# JSON 格式化工具

一个简洁实用的在线 JSON 格式化、压缩和转义工具，支持语法高亮和折叠显示。

## 功能特性

- **美化 JSON** - 将压缩的 JSON 格式化为易读格式，支持 2 空格缩进
- **压缩 JSON** - 移除空格和换行，压缩 JSON 体积
- **转义 JSON** - 将 JSON 转义为可嵌入代码的字符串格式
- **反转义 JSON** - 将转义后的 JSON 还原为原始格式
- **语法高亮** - 不同数据类型（字符串、数字、布尔值、null）以不同颜色显示
- **折叠显示** - 支持折叠/展开对象和数组，方便查看大型 JSON
- **实时预览** - 输入时自动格式化，粘贴后自动美化
- **本地存储** - 自动保存输入和输出状态，刷新页面不丢失
- **字符统计** - 实时显示输入和输出的字符数

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Enter` | 美化 JSON |
| `Ctrl/Cmd + Shift + M` | 压缩 JSON |

## 使用方法

1. 用浏览器直接打开 `json_beautify.html`（无需安装依赖或启动服务）
2. 在输入框中粘贴 JSON 数据，粘贴后会自动美化（格式化）
3. 需要压缩时，点击「压缩 JSON」按钮即可去除多余空白
4. 点击「复制结果」将处理结果复制到剪贴板
